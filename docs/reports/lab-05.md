## 1. Цель работы

Связать форму создания поручения (`TicketNew.vue`) с общим массивом в `ticketsStore.js`: валидная отправка добавляет новую запись со статусом `New` и переводит пользователя на страницу списка `/`, короткая тема (`1–4` символа или пробелы) отклоняется с выводом текста ошибки под полем, нажатие `Enter` не перезагружает страницу, а обновление страницы по `F5` очищает оперативную память браузера.

## 4. Ответы на вопросы для устной защиты (§6 методички)

### 1. Зачем нужен модификатор `.prevent` в `@submit.prevent="onCreate"`?
По умолчанию отправка стандартной HTML-формы (`<form>`) по нажатию кнопки `type="submit"` или клавиши `Enter` вызывает полную перезагрузку страницы браузером. В одностраничном приложении (SPA на Vue 3) перезагрузка страницы уничтожает всё текущее состояние в оперативной памяти (включая записи, добавленные в `ticketsStore.js`). Модификатор `.prevent` вызывает `event.preventDefault()`, отменяя перезагрузку страницы и передавая управление функции `onCreate`.

### 2. Почему у `departmentId` (`siteId`) нужен модификатор `.number` (`v-model.number`)?
В HTML любое значение из поля `<input>` по умолчанию считывается из DOM как строка (например, `"2"` вместо `2`). Модификатор `.number` заставляет Vue автоматически приводить введённое значение к типу `number` в JavaScript (`typeof form.value.departmentId === 'number'`), что необходимо для соблюдения контракта API и модели данных из ЛР2, где внешний ключ справочника — число.

### 3. Где хранится массив записей?
Массив записей `items` хранится в единственном учебном модуле `frontend/src/ticketsStore.js` в виде реактивной ссылки `export const items = ref([...])`. Там же находятся счётчик `nextId` и функция `addItem`. И страница создания (`TicketNew.vue`), и страница списка (`TicketList.vue`) импортируют данные из этого одного модуля.

### 4. Почему нажатие `F5` очищает новые записи?
Потому что в ЛР5 клиентское приложение работает только в оперативной памяти вкладки браузера (JS-память), а сервер `ASP.NET Core` и база данных `PostgreSQL` ещё не подключены. При нажатии `F5` браузер заново загружает страницу и заново инициализирует модуль `ticketsStore.js` с начальным набором из 4 тестовых строк.
