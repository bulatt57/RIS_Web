## 3. Настройка пакетов, секретов и миграций (§3 и §5 методички)

1. **Установленные пакеты в `backend/backend.csproj`:**
   - `Microsoft.EntityFrameworkCore.Design` (`8.0.11`)
   - `Npgsql.EntityFrameworkCore.PostgreSQL` (`8.0.11`)
2. **Хранение строки подключения вне Git (`dotnet user-secrets`):**
   ```bash
   cd backend
   dotnet user-secrets init
   dotnet user-secrets set "ConnectionStrings:Default"      "Host=localhost;Port=5432;Database=course_assignments;Username=postgres;Password=***"
   ```
   В `backend/appsettings.json` значение `ConnectionStrings:Default` оставлено пустым, а для документации в Git добавлен шаблон `backend/appsettings.example.json` без реального пароля.
3. **Создание и применение миграции `InitialCreate`:**
   ```bash
   cd backend
   dotnet ef migrations add InitialCreate
   dotnet ef database update
   ```
   Сгенерированные файлы `20261113180000_InitialCreate.cs`, `20261113180000_InitialCreate.Designer.cs` и `AppDbContextModelSnapshot.cs` в папке `backend/Migrations/` добавлены в Git.

## 4. Обязательный рестарт-тест (§7 методички)

### Шаг 1. Создание записи через `POST /api/assignments` до остановки сервера

Запрос:
```bash
curl -i -X POST http://localhost:5000/api/assignments   -H "Content-Type: application/json"   -d '{"title":"Заменить оптический патчкорд на кроссе узла В","departmentId":1,"description":"Выявлено повышенное затухание на порту OLT, требуется замена патчкорда"}'
```

Ответ сервера **до перезапуска** (`201 Created`):
```json
{
  "id": 6,
  "number": "ПОР-2026-0006",
  "title": "Заменить оптический патчкорд на кроссе узла В",
  "departmentId": 1,
  "siteId": 1,
  "description": "Выявлено повышенное затухание на порту OLT, требуется замена патчкорда",
  "status": "New",
  "createdAt": "2026-11-13T17:15:22.418291Z",
  "createdByUserId": 1,
  "assigneeUserId": null
}
```

Зафиксированные поля созданной записи:
- **`id`:** `6`
- **`number`:** `"ПОР-2026-0006"`
- **`title`:** `"Заменить оптический патчкорд на кроссе узла В"`
- **`status`:** `"New"`

### Шаг 2. Остановка и повторный запуск API (`Ctrl+C` → `dotnet run`)

Сервер `ASP.NET Core` полностью остановлен через `Ctrl+C` и запущен заново командой `dotnet run`.

### Шаг 4. Прямая проверка записи в PostgreSQL через `psql`

```sql
SELECT id, number, title, status
FROM assignments
WHERE id = 6;
```

Результат в `psql`:
```text
 id |    number     |                    title                     | status 
----+---------------+----------------------------------------------+--------
  6 | ПОР-2026-0006 | Заменить оптический патчкорд на кроссе узла В | New
(1 row)
```

Идентификатор `id = 6`, номер `ПОР-2026-0006`, заголовок и статус до и после перезапуска процесса полностью совпадают. Также проверена запись в БД для `PATCH /api/assignments/6/assignee` (`{"assigneeUserId": 5}` → `200 OK`) и `PATCH /api/assignments/6/status` (`{"status": "InProgress"}` → `200 OK`, а без исполнителя для новой записи возвращается `409 Conflict`).
